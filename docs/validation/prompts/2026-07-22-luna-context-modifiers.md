# Modifier Scope

Classify event-local negation and speculation. Attach a modifier only when its cue scopes over the target event itself. Cite the exact cue. Return `ABSTAIN` when scope is ambiguous.

Synthetic contrasts:

- `Protein expression might decrease.`: the decrease event is `SPECULATIVE`.
- `Protein reduction might represent a useful treatment strategy.`: the reduction is not necessarily speculative; the usefulness-as-strategy claim is speculative.
- `Protein did not decrease.`: the decrease event is `NEGATED`.

Do not infer modifiers from numeric uncertainty or general caution.
