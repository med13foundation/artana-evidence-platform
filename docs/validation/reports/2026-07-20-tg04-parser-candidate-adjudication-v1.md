This exposed one-shot experiment tested whether default Sol could use DeepEventMine output as fallible candidates rather than authoritative scientific roles.

## Validity Controls

- fixed prior Sol baseline, parser artifact, paired runner, and source contract preregistered by full SHA-256;
- adversarial preflight before provider execution;
- one `openai:gpt-5.6-sol` call with no explicit reasoning-effort override;
- provider calls: `1`;
- retries: `0`;
- fallback or replay: `0`;
- graph writes: `0`;
- attempt lineage: `pass`;
- provider receipt: `verified_live`;
- terminal state before review: `AWAITING_SOURCE_REVIEW`;
- benchmark score used only as a diagnostic.

The initial preflight vetoed answer coaching and a late, self-referential input seal. The prompt and seal were corrected before the call; repeated preflight returned `GO`.

## Scientific Gain

The candidate corrected the parser and prior Sol baseline in important ways:

- the cis elements, rather than `DR alpha`, became the transactivation Theme;
- `DR alpha proximal promoter` became the Site;
- the cell population and CIITA attribution were retained;
- the inner and outer events remained nested;
- independent reviewers found both events source-supported;
- unsupported content was `ABSENT`.

## Failed Gate

The generated inner event represented `multiple cis elements, especially S and X2` as one Theme operand. One source-only reviewer accepted that plural span; another found it incomplete because `S` and `X2` were not separately machine-addressable. The adversarial adjudicator resolved the disagreement as:

- distinct-participant fidelity: `MERGED`;
- whole-frame completeness: `INCOMPLETE`;
- unsupported content: `ABSENT`;
- comparison: `PARTIAL_GAIN_WITH_TRADEOFF`;
- advancement: `STOP_AND_REDESIGN`.

The fixed baseline preserved separate `S` and `X2` operands but assigned the wrong roles. The candidate repaired the roles but merged the participants. It therefore did not strictly dominate the baseline and cannot advance to untouched sources.

## Root Cause And Next Hypothesis

The remaining failure is not general biomedical comprehension. It is a representation failure for coordinated, internally structured participant phrases: surface inclusion is mistaken for participant preservation.

The next exposed experiment should allow one event to contain a structured or multi-valued Theme that preserves the quantified group and gives `S` and `X2` separate participant identities. All other conditions remain frozen. It advances only if it keeps the corrected roles, nesting, context, and attribution with zero unsupported claims and separately addressable participants.
