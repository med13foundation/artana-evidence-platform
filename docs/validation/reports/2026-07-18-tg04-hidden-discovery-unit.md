## Categorical Result

The raw extractor output classified the unit as `FINDING` and proposed one
`DECREASE` event with `ASSERTED` epistemic status and `SUPPORT` polarity. It
preserved three typed material arguments:

- `IL-4` as `CAUSE`;
- `the number of FOXP3+ cells` as `THEME`;
- `iTreg-driving conditions` as `CONTEXT`.

Its exact event span, relation cue, and argument spans were copied from the
source. This is promising semantic behavior, but it remains an unverified raw
attempt and cannot be counted as an accepted claim.

## Exact Failure

The expected `unit_id` was 76 characters. Luna returned a 103-character value
that matched the first 54 characters and then blended other opaque hash text
into the identifier. The semantic binder correctly rejected the mismatch.

Consequences were fail-closed:

- accepted events: `0`;
- verifier calls: `0`;
- invalid agent outputs: `1`;
- verified provider receipts: `1` for the extractor;
- gate decision: `STOP_AND_RECALIBRATE`;
- persistence authorized: `false`.

## Root Cause

The contract assigns two unrelated responsibilities to the model: scientific
interpretation and byte-exact reproduction of a long machine identifier. The
first responsibility appeared plausible in this attempt; the second failed and
prevented scientific verification.

Opaque identity is transport metadata. It is already known by deterministic
code and should not be regenerated by an LLM. Keeping it in the scientific
output schema creates an avoidable failure mode without adding evidence safety.
The safety property we need is that an output is bound to the invocation's
frozen unit, not that the model can copy a 76-character hash.

## Next Remediation

1. Define provider-facing extraction and verification payloads that contain
   only categorical scientific judgments and source spans.
2. Bind `unit_id`, source hash, input hash, and invocation identity
   deterministically in the audited transport envelope.
3. Keep fail-closed span, trigger, argument, receipt, and provider-lineage
   checks unchanged.
4. Add adversarial tests proving that model text cannot replace, omit, or
   redirect the deterministic unit identity.
5. Run a non-qualifying transport smoke test, then pre-register a fresh hidden
   source unit for the next scientific qualification attempt.

The failed unit must not be silently rerun and reported as an independent
discovery. Any replay used to diagnose the transport fix must be labeled
non-qualifying.
