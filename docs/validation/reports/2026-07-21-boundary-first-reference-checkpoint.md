# Boundary-First Reference Checkpoint

## Decision

`PIVOT_TO_PUBLIC_GOLD`

This was the final permitted custom-reference construction attempt. It stopped
before boundary agreement, semantic annotation, packet freezing, or the exposed
verification experiment.

## Protocol And Custody

The five already exposed full abstracts in the sealed local corpus were the only
permitted inputs. Boundary Agent A (`gpt-5.6-sol`, high reasoning) produced 76
offset-bound proposed assertion units, including categorical core participant
spans and unit classifications. It did not receive the previous 31 discovery
scope IDs, prior claim packets, or prior adjudication artifacts.

Boundary Agent B was started with a different available configuration
(`gpt-5.6-luna`, max reasoning) under the identical source-only contract. It
did not produce its required JSON artifact within the bounded execution window
and was stopped. Consequently, there is no second independent boundary set and
no third-agent boundary resolution request.

The environment can record separate task identifiers and instructions, but it
cannot independently audit every filesystem read performed inside the agent
runtime. No untouched source was selected or accessed by this checkpoint runner.
No Artana framing or verification call, graph write, fallback, repair cycle, or
promotion path was invoked.

## Gate Result

Boundary/participant disagreement is not computable without two completed,
valid blinded boundary inventories. Treating that as zero disagreement or using
Agent A as gold would be false evidence. The gate therefore fails closed.

| Measure | Result |
| --- | --- |
| Full abstracts available | 5 |
| Valid completed boundary agents | 1 of 2 required |
| Proposed units from Agent A | 76 |
| Boundary agreement | NOT_COMPUTABLE |
| Included semantic packets | 0 |
| Exposed verification run | NOT_RUN |
| Untouched sources | 0 by runner |
| Promotion | Disabled |

## Permanent Pivot

The custom agent-generated reference path is now closed. Future scientific
qualification must use public expert-annotated biomedical event/relation data,
with its published annotation guidelines, train/development/test split, and
license recorded before Artana is evaluated. Candidate sources include expert
annotated event-extraction and relation-extraction corpora; selection must be
made prospectively and independently of Artana outputs.

This is not a claim that Artana failed the science. It is a claim that the
project could not construct a reproducible, independent custom gold reference
from the exposed abstracts under the required protocol, so that path cannot
validly qualify Artana.
