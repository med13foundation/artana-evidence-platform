# PR45 Expert Source Export Writer Summary

## Run Context

- Branch: `alvaro/evidence-pr45-expert-source-export-writer`
- Base branch: `alvaro/evidence-pr44-expert-source-export-metadata`
- Scope: Evidence API expert/shadow study source-export generation

## Goal

Make PR44 source-export envelopes generated by a typed writer instead of
hand-authored JSON.

## Root Cause

PR44 made selection-review and review-ranking source exports self-describing,
strict, and literal. That closed the identity mismatch gap, but operators still
had to assemble the source-export envelopes by hand. Hand assembly can create
schema drift, source identity drift, or destructive output mistakes before the
PR43 bundle builder ever sees the files.

## Code Changes

- Added `artana_evidence_api.evidence_selection.source_export_writer` with a
  typed request/result contract for writing matched source exports.
- The writer loads collected selection-review labels from a strict
  `selection_reviews` envelope and review-ranking labels from the existing
  strict calibration study schema.
- The writer builds both PR44 source-export envelopes with the same
  `EvidenceSelectionSourceExportIdentity`, preserving exact canonical timestamp
  and literal identity validation.
- The writer rejects output paths that would overwrite either source input and
  rejects identical selection-review/review-ranking output paths.
- The writer serializes both outputs before writing, writes sibling temp files,
  and replaces final outputs only after both temp writes succeed. Temp files are
  cleaned up on paired-write failure. Existing final outputs are moved to
  backups before the final commit phase and restored if any later replace fails.
- Added `scripts/build_evidence_selection_source_exports.py` as a thin CLI
  wrapper around the service writer.
- Added Makefile lint/type-check coverage and CI planner routing so script-only
  changes to the new CLI run the Evidence API gate.
- Updated validation docs to show the source-export writer command before the
  final expert-study bundle command.

## Interpretation

PR45 does not create real expert labels. It reduces the chance of operator
error once expert/shadow labels exist: collected review JSON can now be turned
into matched, strict, self-describing source exports through one typed writer
before the PR43 bundle builder computes hashes and source manifests.
